# BottleCRM

BottleCRM: мультитенантная CRM, которая охватывает лиды, компании, контакты, сделки, обращения
в поддержку, задачи и счета.

## Что такое BottleCRM {#what-bottlecrm-is}

BottleCRM распространяется под лицензией MIT и разворачивается на своём сервере: вы
запускаете её в своей инфраструктуре, ограничений по числу пользователей нет, платных функций тоже.

## Как всё устроено {#how-it-fits-together}

Три клиента (веб-приложение на SvelteKit, мобильное приложение на Flutter и REST API) работают с
одним бэкендом на Django REST Framework. Изоляция тенантов обеспечивается механизмом Row-Level
Security в PostgreSQL по сессионной переменной `app.current_org`, а не только кодом приложения:
middleware приложения задаёт эту переменную по JWT аутентифицированного пользователя при каждом
запросе, а база данных применяет её независимо от собственных фильтров ORM по организации.
